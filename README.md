# 47的健身小帮手 · 动作搜索 + 训练视频 + 今日计划

一个零依赖的静态网站。**不需要安装任何东西**，双击 `index.html` 就能在浏览器里打开。

---

## 一、六个页面

| 文件 | 作用 | 用户怎么到达 |
|---|---|---|
| `index.html` | **首页**：大标题「今天你想练什么？」+ 搜索框 + 6 个大分类卡片 | 直接打开 |
| `search.html` | **搜索结果页**：搜索框 + 筛选器 + 动作卡片列表 | 首页点分类 / 搜索后跳转 |
| `exercise.html` | **动作详情页**：步骤、常见错误、提示、注意事项 | 点任意动作卡片 |
| `videos.html` | **训练视频页**：顶部横向封面选择条 + 下方预览 | 顶部导航「训练视频」 |
| `plan.html` | **今日计划页**：卡片式安排今天的动作 + 点亮记组数 | 顶部导航「今日计划」 |
| `editor.html` | **视频录入工具**（站长用）：填表 → 生成代码 → 复制 | 视频页右上角「＋ 添加视频」 |

页面之间用顶部导航互相切换：**动作搜索** / **训练视频** / **今日计划**。

也可以直接把 `search.html?muscles=背` 这样的地址发给别人。

## 三、怎么加一个训练视频

打开 `data/videos.js`，在数组末尾 `];` 之前加一段：

```js
  {
    id: 'unique-id',                 // 英文小写+横线，不能重复
    athlete: '运动员名字',
    title: '视频标题',
    sport: '项目',                   // 健美 / 举重 / 田径 / 足球 ...
    emoji: '🏋️',                     // 封面上的图标
    tone: 0,                         // 封面配色 0–7
    duration: '12:30',
    cover: '',                       // 封面图地址，留空就用渐变色块
    url: '',                         // 视频链接，粘贴 B站/YouTube 普通链接即可
    note: '一句话说明这个视频值得看什么',
    tags: ['背', '力量']
  },
```

### 视频链接怎么填

**直接粘贴浏览器地址栏里的链接就行**，网站会自动转成播放器：

| 你粘贴的链接 | 实际效果 |
|---|---|
| `https://www.douyin.com/...modal_id=7580303222796310449` | 自动变成**抖音官方竖屏播放器**（9:16） |
| `https://www.douyin.com/video/7580303222796310449` | 同上 |
| `https://www.bilibili.com/video/BV1xx411c7mD` | 自动变成 B站播放器（16:9） |
| `https://youtu.be/dQw4w9WgXcQ` | 自动变成 YouTube 播放器（16:9） |
| 抖音短链 `https://v.douyin.com/xxxxx/` | ⚠ **不能嵌入**，拿不到视频 ID，需换成带 `modal_id=` 的完整链接 |
| 其他站点（腾讯视频等） | 不能嵌入，只显示「在新窗口打开」按钮 |
| 留空 `''` | 只预览封面，不播放 |

### 抖音为什么能嵌入

抖音 PC 网页版本身有 `X-Frame-Options` 限制，**不能直接 iframe 那个页面**。但抖音开放平台提供了官方播放器接口：

```
https://open.douyin.com/player/video?vid=<视频ID>&autoplay=0
```

网站会自动从你粘贴的链接里提取视频 ID（`modal_id=` 或 `/video/` 后面那串数字），拼成这个地址。抖音是竖屏，所以播放区会自动切成 **9:16** 的窄幅。

**注意两点**：
- 只能用**带 `modal_id=` 的完整链接**。抖音 App 里「复制链接」给的是 `v.douyin.com` 短链，里面没有视频 ID，无法嵌入——请在电脑浏览器里打开视频，复制地址栏的链接
- 视频被作者删除、设为私密，或限制地区，播放器就播不了（这是抖音侧的限制，网站无法绕过）

### 封面

- `cover: ''` → 用渐变色块 + emoji 当封面（**默认样子**）
- `cover: 'data:image/jpeg;base64,...'` → **拖拽上传的图片**（录入工具自动生成）
- `cover: 'images/xxx.jpg'` → 你自己放进 images 文件夹的图片

封面条会自动更新，不用改任何其他文件。

### 不想手写代码？用录入工具

打开视频页底部（或右上角）的 **「＋ 添加视频」**，或者直接双击 `editor.html`。

工具顶部有两个模式：

| 模式 | 用途 | 生成的代码怎么用 |
|---|---|---|
| **新增视频** | 加一条全新的 | 粘贴到 `data/videos.js` 的 `];` **前面** |
| **编辑已有的** | 改已经加过的（比如补封面） | 找到文件里 `id: 'xxx'` 的那一段，**整段替换** |

切到「编辑已有的」后，下拉框会列出 `data/videos.js` 里所有视频（显示成「运动员 · 标题」）。选中哪条，表单就自动填入它现在的数据，改完复制、替换即可。

> 编辑模式下 **id 会锁定不能改**（改了就等于新增一条，会重复）。工具也会在代码框上方提示你要替换哪一段。

左边填表，右边实时生成：

- **封面预览**：和你视频页上看到的一模一样（改配色、改 emoji 立刻变）
- **生成的代码**：可以直接复制的完整代码块
- **「复制代码」按钮**：点一下进剪贴板

工具会自动帮你：
- 检查链接能不能嵌入播放（抖音/B站/YouTube 打勾，其他站点给警告）
- 检查 id 有没有和现有视频重复（重复了会提示你点「换一个」）
- 检查必填项有没有漏
- 处理引号转义（标题里有 `'` 或 `"` 也不会生成坏代码）
- 标签自动按逗号拆成数组

> 这个页面只是本地生成代码，不会把数据发到任何服务器。生成完还得你自己粘贴到文件里。

### 封面图：直接拖进去就行

封面预览区是个**拖拽区**：

1. 从文件资源管理器里把图片**拖到封面预览上** → 松开
2. 图片自动**裁剪成 16:9、压缩到 480×270**，写进 `cover` 字段
3. 右边代码立刻更新，复制粘贴即可

也支持：
- **点击**预览区 → 打开文件选择框
- **Ctrl + V** 粘贴剪贴板里的图片
- 点「清除」→ 回到渐变色块封面

**为什么是压缩后内嵌**：纯静态网站没有后端，浏览器不能把文件写进你的硬盘。所以图片会转成 base64 直接存在 `cover` 字段里——好处是**不用另存文件、不用担心路径写错、图片跟着数据走**。代价是 `data/videos.js` 会变大（一张封面约 30–60KB）。

> 如果图片特别大或视频很多，建议改用 `images/xxx.jpg` 路径方式：自己把图放进 `images` 文件夹，在 `cover` 字段写路径。两种方式可以混用。

## 四、今日计划页怎么用

打开顶部导航的「今日计划」。页面分两栏：**左上角先选部位**，右边安排具体动作。

### 第一步：左上角「今天练什么？」

左上角有一张卡片，列出 6 个部位大类 + 「全部动作」：

```
今天练什么？
选一个部位，加动作时只会出现这个部位的动作

🏋️ 练胸          3 个
🧗 练背          3 个
🤸 练肩          3 个
🦵 练腿          4 个
🔥 练核心        4 个
🏃 有氧训练      4 个
──────────────────
📋 全部动作      23 个
```

- 点一行就选中（橙色高亮），再点「全部动作」可以取消限制
- 选中后卡片下方会提示：**已选「练背」，加动作时只会显示背部的 3 个动作**
- 这个选择会**存下来**，第二天才重置

> 分类定义在 `assets/search-core.js` 的 `GROUPS`，首页的六个大卡片和这里共用同一份。改一处，两个页面一起变。

### 第二步：右边安排动作

默认给你 **4 张空卡片**，每张写着「第 1 个动作」「第 2 个动作」…

- 底部 **＋ 添加动作** 按钮：加一张卡片
- 每张卡片右上角 **✕**：删掉这张
- 删光了会自动补一张，不会出现空白页

### 选择动作：居中搜索面板

点任意空卡片（或已填卡片空白处换动作），屏幕中央弹出搜索面板：

```
┌─────────────────────────────────────┐
│  [搜索动作，填入第 1 个动作]    ✕   │
├─────────────────────────────────────┤
│  范围：练背   [看全部动作]    3 个  │
├─────────────────────────────────────┤
│  最近用过  [哑铃单臂划船]           │
├─────────────────────────────────────┤
│  高位下拉        背 · 入门 · 拉力器  │
│  哑铃单臂划船    背 · 入门 · 哑铃    │
│  引体向上        背 · 高阶 · 单杠    │
└─────────────────────────────────────┘
```

- **列表只显示你选的部位**，简洁明了
- 顶部那行显示当前范围，右边有个 **看全部动作** 按钮，临时想跨部位加一个动作时点它
- 搜索框自动聚焦，**输入即筛选**（同义词也生效，搜「练背」能命中）
- **最近用过**的动作排成快捷标签，一点就填
- ↑↓ 键选择、回车确认、Esc 关闭
- 填进去后卡片会闪一下，确认"进去了"

### 记组数
每张已填入的卡片下半部分是这样：

```
完成组数                    2 / 4
● ● ○ ○                    − 4 ＋
```

- **点圆点** → 点亮到这一颗（点第 3 颗，前 3 颗一起亮，带波浪动画）
- **再点最后一颗亮点** → 取消它（4/4 → 3/4）
- 右侧 **− ＋** 调整总组数（1–12 组），减少时已完成组数会自动裁剪
- 一张卡片全部完成时，卡片底色会变实，表示这个动作做完了
- **刚好做满的那一刻，会从你点的那颗圆点炸开一圈烟花**

### 两级庆祝特效

**一级：单个动作做满**

- 爆点一团柔光扩散开
- **两波粒子**：第一波 26 颗飞得远（60–175px），150ms 后第二波 16 颗飞得近（28–105px），形成层次
- 每颗的角度、距离、大小、旋转、延迟都有随机抖动，不会像机械的菊花
- 约 **30% 是长条彩带**（会自转），其余是圆形粒子
- 粒子带重力下落（落点比起点低 38px），两圈光环先后扩散
- 卡片轻微回弹

**二级：整份计划全部做完**

- 屏幕上 **5 个爆点连炸**（每 130ms 一个），每个爆点 32 颗粒子、飞得更远（80–250px）、尺寸更大
- **48 条彩带从屏幕顶部撒落**，边转边飘，2.2–3.6 秒落到底
- 屏幕中央弹出横幅：**🎉 今天的训练全部完成！**（带组数统计，3.5 秒后淡出）
- 只在"从没做完变成刚做完"的那一刻触发一次，取消再重做会重新触发

> 全部是纯 CSS 写的，没有引入任何第三方库。粒子数量、颜色、飞行距离都在 `assets/plan-page.js`：`burst()` 控制粒子，`confetti()` 控制彩带，`FX_COLORS` 是配色。系统开启「减弱动态效果」时，粒子全部不生成，只保留横幅提示。

顶部有一条橙色进度条，显示 **已完成组数 / 总组数**，还有动作完成数。

### 数据保存
- 自动存在浏览器本地，**刷新不丢**
- **按日期存**：第二天打开自动重置成新的 4 张空卡片
- 「清空今天的计划」按钮可以手动重置
- 如果浏览器禁止本地存储（比如某些隐私模式），页面会显示一条橙色提示，告诉你刷新会丢

## 五、怎么加一个新动作

1. 打开 `data/exercises.js`
2. 找到数组末尾的 `];`
3. 在它前面复制粘贴下面这段模板（注意末尾的逗号）：

```js
  {
    id: 'your-exercise-id',            // 英文小写+横线，不能重复
    name: '动作名称',
    aliases: ['别名1', '别名2', 'English Name'],
    primaryMuscle: '背',               // 背 / 胸 / 腿 / 臀 / 肩 / 手臂 / 核心 / 全身
    secondaryMuscles: ['肱二头肌'],
    equipment: ['哑铃'],               // 无器械 / 哑铃 / 杠铃 / 单杠 / 拉力器 / 壶铃 / 跳绳 ...
    category: '力量',                  // 力量 / 有氧 / 核心 / 拉伸 / 热身
    difficulty: '入门',                // 入门 / 进阶 / 高阶
    metrics: '次',                     // 次 / 秒 / 分钟 / 距离
    video: '',                         // 先留空，以后填 B站链接
    contraindication: '',              // 没有就留空字符串
    steps: ['第一步', '第二步', '第三步'],
    mistakes: ['常见错误一', '常见错误二'],
    tips: ['提示一']
  },
```

4. 保存，刷新浏览器。

**首页卡片上的数字会自动更新**，筛选器里的新选项也会自动出现，不用你手动改任何东西。

## 六、怎么改首页的六个大分类

打开 `assets/home.js`，最上面有个 `GROUPS` 数组：

```js
var GROUPS = [
  { label: '练胸',     emoji: '🏋️', muscles: ['胸'],       tone: 0 },
  { label: '练背',     emoji: '🧗', muscles: ['背'],       tone: 1 },
  { label: '练肩',     emoji: '🤸', muscles: ['肩'],       tone: 2 },
  { label: '练腿',     emoji: '🦵', muscles: ['腿', '臀'],  tone: 3 },
  { label: '练核心',   emoji: '🔥', muscles: ['核心'],     tone: 4 },
  { label: '有氧训练', emoji: '🏃', category: '有氧',      tone: 5 }
];
```

- `label` 卡片文字
- `emoji` 卡片图标（想换成纯文字也行）
- `muscles` 对应的肌群，可以写多个，比如练腿同时包含腿和臀
- `category` 按类别筛选（有氧用这个）
- `tone` 配色，可选 0–7

下面的 `MORE` 数组是次要入口（练手臂、练全身、看全部）。

## 七、怎么加"用户会搜但数据里没有"的词

比如用户搜「练背」「腹部」「瘦腿」「减脂」，这些词数据里并不存在。翻译工作由同义词表负责。

打开 `assets/search-core.js`，找到 `SYNONYMS`：

```js
var SYNONYMS = {
  '腹': '核心', '腹部': '核心', '腹肌': '核心',
  '练背': '背', '背部': '背',
  '瘦腿': '腿',
  '减脂': '有氧',
  ...
};
```

左边是用户可能输入的词，右边是数据里真实存在的值。加一行就多认一个说法。

另外系统会自动去掉「练 / 训练 / 想练 / 今天」这类前缀，所以「练背」不写进表里也能搜到。

## 八、外观怎么调（橙色流动玻璃）

所有视觉都在 `assets/style.css` 一个文件里，不用改 HTML。

### 想换背景的橙色
文件最上面的 `body::before` 和 `body::after` 里，那几行 `radial-gradient` 就是流动的光斑。改里面的颜色值即可：

```css
radial-gradient(42% 44% at 18% 26%, rgba(255, 132, 45, .58), transparent 66%),
                                  ↑ 这就是光斑颜色和浓度
```

- 数字越小越淡，`.30` 左右会比较含蓄
- 想换色系，把 `rgba(255,132,45,…)` 换成别的 RGB 值
- 流动速度看下面的 `animation: flow-a 28s` —— 数字越大越慢

### 想调玻璃的模糊程度
最上面 `--blur: 18px;` 改大更糊、改小更透。

### 想调卡片的白玻璃浓度
`--glass: rgba(255,255,255,.55);` —— 最后一位是透明度，`.40` 更透，`.80` 更实。

### 想换主色（按钮、选中状态、标题）
改 `--brand` 和 `--brand-dark` 两个值。

### 大卡片的分类色
`assets/home.js` 里每个分类的 `tone` 数字（0–7），对应 `style.css` 里 `.tone-0` 到 `.tone-7`。这些颜色只在卡片顶部形成一层很淡的光，卡片本身还是白玻璃。

> 注意：毛玻璃效果在很老的浏览器（IE、旧版 Safari）上不生效，会自动降级成不透明白色，内容照样能看。

## 九、几个必须注意的规则

### 1. 每条之间要有逗号
数组里每一条 `{ ... }` 后面都要跟英文逗号 `,`，**最后一条可以不加**。漏逗号会导致白屏。

### 2. 只能用英文标点
`'` `"` `,` `:` —— 不要用中文的 `'` `"` `，` `：`。

### 3. 单引号里不能出现单引号
错误：`'动作里的'引号'会出问题'`
正确：`"动作里的'引号'没问题"`（外面用双引号）

### 4. 同一个肌群要写一样
一处写「背」、另一处写「背部」，筛选器里就会出现两个选项。

### 5. 白屏了怎么办
按 `F12` 打开控制台，红色报错会告诉你是哪一行、什么符号写错了。

- ✅ 「今天你想练什么？」+ 六个大分类卡片（带动作数量）
- ✅ 搜索框即时出建议，回车看全部结果
- ✅ 键盘 ↑↓ 选择建议，Esc 关闭，`/` 快速聚焦
- ✅ 次要入口：练手臂 / 练全身 / 看全部

**搜索页**
- ✅ 关键词搜索（动作名、别名、肌群、器械、类别都能命中）
- ✅ 多关键词（输入「哑铃 背」同时匹配）
- ✅ 同义词（练背、腹部、瘦腿、减脂…）
- ✅ 四个筛选器，选项自动从数据生成
- ✅ 搜索和筛选叠加，地址栏同步，可以直接分享链接

**详情页**
- ✅ 步骤、常见错误、训练提示、注意事项（橙色警示框）
- ✅ 视频位预留，填了链接就显示按钮

**训练视频页**
- ✅ 顶部横向封面选择条（比分类卡片大，16:9 封面比例）
- ✅ 点选封面 → 下方大预览区联动
- ✅ 左右箭头翻页、鼠标滚轮横向滚动、方向键切换
- ✅ B站 / YouTube 链接自动转播放器
- ✅ 封面图留空时自动用渐变色块 + emoji

**今日计划页**
- ✅ 左上角「今天练什么」部位卡（6 大类 + 全部动作），选中后存起来
- ✅ 加动作时搜索面板**只显示所选部位的动作**
- ✅ 面板顶部可临时「看全部动作」
- ✅ 默认 4 张卡片，可自由增删
- ✅ 空卡片显示「第 N 个动作」
- ✅ 居中搜索面板 + 最近用过快捷填入 + 键盘操作
- ✅ 点圆点记组数，逐颗点亮带波浪动画
- ✅ 每张卡片可调总组数（1–12）
- ✅ 顶部进度条 + 动作完成计数
- ✅ 本地保存，按日期自动重置

**通用**
- ✅ 顶部导航：动作搜索 / 训练视频 / 今日计划
- ✅ 橙色流动玻璃风格（背景缓慢漂移，卡片毛玻璃）
- ✅ 手机端自适应
- ✅ 页脚免责声明

**还没做**
- ⬜ 训练计划（把动作组合成计划）
- ⬜ 图片（按你的要求先不放）
- ⬜ 用户分享社区

## 十一、以后要上线时

现在这个版本是本地文件，别人访问不了。要放到网上需要：

1. 注册 [Cloudflare Pages](https://pages.cloudflare.com/) 或 [Vercel](https://vercel.com/)（免费）
2. 把文件夹上传到 GitHub
3. 平台连接仓库后自动部署，给你一个网址
4. 买个域名（约 60–80 元/年）绑定上去

**注意**：当前是纯前端渲染，搜索引擎收录效果一般。以后要靠搜索流量，需要改成每个动作一个独立静态页（升级到 Astro 框架），到时候再说。
