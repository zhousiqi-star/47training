# 947fitness

一个零依赖的静态网站。**不需要安装任何东西**，双击 `index.html` 就能在浏览器里打开。

---

## 一、两个页面

| 文件 | 作用 | 怎么到达 |
|---|---|---|
| `index.html` | **今日训练（首页）**：选部位 → 加动作 → 点圆点记组数 → 填重量 → **封存今天的清单** | 直接打开 |
| `history.html` | **训练历史**：一页看完这个月，点一天看那天的清单，往下是每个动作的重量 | 顶部导航「训练历史」 |

顶部导航只有两项：**今日训练** / **训练历史**。

## 三、首页（今日训练）怎么用

页面是**一条单列**（手机优先，桌面把同一套语言摊开）：顶部日期 → 读数板 → 练什么 → 动作卡列表 → 底部主操作。

### 第一步：左上角「今天练什么？」

列出 6 个部位大类 + 「全部动作」。点一行就选中（青色实心高亮），再点「全部动作」取消限制。

- 选中后下方提示：**已选「练背」，加动作时只会显示背部的 14 个动作**
- 选择会跟着记录一起存下来，第二天才重置

> 分类定义在 `search-core.js` 的 `GROUPS`。想改分类文案或归属，只改这一处。

### 第二步：安排动作

默认 4 张空卡片，写着「第 1 个动作」…

- 底部 **＋ 添加动作**：加一张卡片
- 卡片右上角 **✕**：删掉这张
- 删光了会自动补一张

### 选择动作：居中搜索面板

点任意空卡片（或已填卡片空白处换动作），屏幕中央弹出面板：

- **列表只显示你选的部位**，一眼看完
- 顶部右侧有「**看全部动作**」，临时想跨部位加一个时点它
- 搜索框自动聚焦，**输入即筛选**（同义词也生效，搜「练背」能命中）
- **最近用过**的动作排成快捷标签，一点就填
- ↑↓ 选择、回车确认、Esc 关闭

### 记组数

```
完成组数                    2 / 4
● ● ○ ○                    − 4 ＋
```

- **点圆点** → 点亮到这一颗（带波浪动画）
- **再点最后一颗亮点** → 取消它（4/4 → 3/4）
- 右侧 **− ＋** 调整总组数（1–12 组），减少时已完成组数自动裁剪
- 卡片做满 → 底色变实 + **从你点的那颗圆点炸开烟花**

### 记重量（可选）

每张动作卡右侧有一个小凹槽，填数字就行，**单位固定是 kg**：

```
重量   [ 45 ] kg
```

- **只填数字**，不要写「kg」「公斤」——写了也会被过滤掉
- 没填就空着，不会记成 0
- 只填一次也行：填过的重量会进训练历史，在历史页按动作排成一条**销轨**
- 没有重量的动作（引体向上、平板支撑这类）就空着，历史页那行会显示「—」

### 封存今天的清单（做完后按这一下）

**只有按了这一下，这一天在历史里才算闭上。**

- 底部 **封存今天的清单**：把今天这份清单写进训练历史，盖上一个时刻（按钮变成「已封存 · 21:15」）
- 读数板下面那行也会跟着报：`已封存 21:15 · 6 / 6 个动作已完成`
- **没封存也不会丢**：你在页面上的每一次改动本来就在往日志里写草稿（这是防丢的安全网），
  只不过历史里那一天会画成一条**开口的弧**，而不是合上的印
- 再按一次 = 更新时间戳（比如封存后又补了一组）
- 「清空今天的记录」会把封印一起作废

### 输出这张记录（封存之后才有）

做完动作、封存之后，读数板那行右边会多出一个「输出记录」。点它出来一张卡：

- **1080 × 1620 竖版**（2:3，朋友圈 / 小红书通用）：947 徽章 + 日期 → 一条细线 → 一整块实心青的读数板
  （完成组数、凹槽进度、「今天做满了」）→ 动作清单（动作 · 完成组数）→ 封存印 + 一行合计
- **图片里不写重量**：卡面只有"练了什么、做了几组"。重量在历史页的销轨里，以及下面那段复制的文字里
- **保存图片**：下载成 `947fitness-2026-09-20.png`；手机上也可以直接**长按那张卡**存进相册
- **复制文字**：一段纯文本（带重量），粘到微信 / 备忘录里就行
- 卡上**没有环带、没有完成率、没有打卡天数、没有加油语**——只陈列今天做过的事
- 读数板与清单之间、清单与页脚之间都留 56px 台面：**不为了填满把中间挤死**；动作多了自动分两栏、行高自适应，不裁切
- 万一浏览器不让自动复制（用 `file://` 打开时会发生），会就地弹出一块输入面并**把文本选中**，
  按 Ctrl / ⌘ + C 即可，不会把你留在"复制失败"那句话上

> 门槛是刻意的：你的工作方式是"做完全部动作才输出一张清单"。
> 所以**没封存的一天不给输出**——封存是盖印，输出是取走那张卡。

### 两级庆祝特效

**单个动作做满**：爆点柔光 + 两波粒子 + 彩带 + 两圈光环，卡片轻微回弹。

**整份记录全部做完**：屏幕上 5 个爆点连炸 + 48 条彩带从顶部撒落 + 中央弹出横幅。

**封存那一下**：比上面两级都低一档——从按钮上炸开一圈，横幅写「今天的清单已封存」。
彩带只留给"全部做满"那一刻，封存是盖章，不是放烟花。

> 纯 CSS 写的，零依赖。系统开启「减弱动态效果」时粒子不生成，只保留横幅。

### 数据保存

- 自动存在浏览器本地，**刷新不丢**
- **按日期存**：第二天打开自动重置成新的 4 张空卡片
- 手机和电脑的进度**不互通**（各存各的）

## 四、训练历史页怎么读

这一页的设计语言只有一句话：**一天 = 一枚环，环是"这一天被确认过"的印。**

```
        ┌─ 环的形状 ─────────────────────────────────┐
        │  ● 闭合的圆   = 已封存（你在首页按过封存）    │
        │  ◐ 开口的弧   = 有记录，但还没封存（含今天）  │
        │  ○ 空槽       = 那天没练，就是一个凹进去的孔  │
        └────────────────────────────────────────────┘
```

- **环下的小字** = 那天完成了几组；**环的粗细**也按同一个数走（这个月里最重的那天最粗）
- **环里的数字** = 那天的日期（这是日历，先让人找到"哪天"）
- **今天**的数字是青色的，弧的末端有一根指针
- **点任意一天** → 那天的清单就地展开：每个动作做了几组、用的多少 kg；安排了没做完的会点出来

页面上方是一块**铭牌**（挖出来的凹槽，数字刻在里面）：这段区间的**训练天数 / 完成组数 / 最重的一组**，
再加一句中性对比（「上月同期 154 组，多 13 组。」——只陈述，不催人）。

**区间**分三档：

| 档位 | 看什么 |
|---|---|
| 本月 | 7 列环历，用 ‹ › 翻到上一个月 |
| 本年 | 12 栏柱子，柱高 = 那个月完成的组数，12 栏共用同一条轴；点一栏跳进那个月 |
| 全部 | 一年一行（天数 / 组数 / 最重），点进去看那一年的 12 栏 |

再往下是**重量**：每个记过重量的动作一行水平凹槽，
**销子（青色）= 最近一次**，**刻痕（灰色）= 最重的一次**，所有动作共用一条 kg 轴，所以动作之间可以直接比。

> 这一页**不评价你**：没有完成率、没有连续打卡、没有「超过 80% 的用户」。
> 与上期的比较只写事实，不带箭头催促。

### 删除记录（两处）

| 想删什么 | 在哪 | 会连带走什么 |
|---|---|---|
| **某一天** | 点开那一天 → 下方「删除这天的记录」 | 那天消失。**删的是"今天"的话，首页的动作卡也一起清空** |
| **一段区间** | 页面底部「清空9 月的记录（13 天）」 | 按钮跟着当前区间走：本月 / 本年 / 全部 |

- 两处都先弹确认框，**点了确定才动手**
- 「清空本月」只动这个月，上个月一天都不会少
- 删掉"今天"为什么要连工作区一起清：首页那几张动作卡里还留着今天的动作，
  只删日志的话，你回去随便点一下圆点，这一天又会自己写回来
- 两处都是**彻底删除**。数据只在这台设备上，没有云端备份可以恢复

### 空的时候会看到什么

- 一次都没练过：环历全是空槽，下面写「还没有任何记录。今天练完，在首页按一下「封存今天的清单」，这里就会长出第一枚印。」
- 浏览器不给本地存储（隐私模式等）：顶部会有一条黄色提示告诉你读不到日志——
  **空白不等于"你没练"**，原因必须说出来

## 五、怎么加一个新动作

打开 `exercises.js`，在数组末尾 `];` 之前加一段：

```js
  {
    id: 'your-exercise-id',            // 英文小写+横线，不能重复
    name: '动作名称',
    aliases: ['别名1', '别名2', 'English Name'],
    primaryMuscle: '背',               // 背 / 胸 / 腿 / 臀 / 肩 / 手臂 / 核心 / 全身
    secondaryMuscles: ['肱二头肌'],
    equipment: ['哑铃'],               // 无器械 / 哑铃 / 杠铃 / 单杠 / 龙门架 / 壶铃 / 跳绳 / 器械 / 卧推凳 / 深蹲架 / 罗马椅
    category: '力量',                  // 力量 / 有氧 / 核心 / 拉伸 / 热身
    difficulty: '入门',                // 入门 / 进阶 / 高阶
    metrics: '次',                     // 次 / 秒 / 分钟 / 距离
    contraindication: '',
    steps: ['第一步', '第二步', '第三步'],
    mistakes: ['常见错误一'],
    tips: ['提示一']
  },
```

**部位卡上的数字会自动更新**，新出现的肌群也会自动加进部位卡。

## 六、怎么改首页的部位分类

打开 `search-core.js`，找到 `GROUPS`：

```js
var GROUPS = [
  { key: 'chest',    label: '练胸',   noun: '胸部', emoji: '🏋️', muscles: ['胸'], tone: 0 },
  { key: 'back',     label: '练背',   noun: '背部', emoji: '🧗', muscles: ['背'], tone: 1 },
  ...
];
```

- `label` 显示文字
- `noun` 提示文案里用的名词（「只会显示**胸部**的 3 个动作」）
- `muscles` 对应的肌群，可写多个
- `category` 按类别筛选
- `tone` 是历史遗留字段，**现在已经不用了**（全站只有一支电光青，部位靠 emoji 和名字区分），留着不影响

## 七、怎么加"用户会搜但数据里没有"的词

用户搜「练肩」「腹部」「瘦腿」这些，数据里并不存在。翻译工作由 `search-core.js` 的 `SYNONYMS` 负责：

```js
var SYNONYMS = {
  '腹': '核心', '腹部': '核心', '腹肌': '核心',
  '练背': '背', '背部': '背',
  '瘦腿': '腿',
  ...
};
```

左边是用户可能输入的词，右边是数据里真实存在的值。另外系统会自动去掉「练 / 训练 / 想练 / 今天」这类前缀。

## 八、外观怎么调

所有视觉都在 `style.css` 一个文件里。**改之前先看 `DESIGN.md`**——那里写清了这套系统的规则和禁区。

最要紧的三条：**强调色只有一支电光青**；**没有半透明面、没有模糊、没有彩色发光**；
**全站只有一处大面积青色**——首页那块读数表头。

| 想改什么 | 改哪里 |
|---|---|
| 主色（电光青） | `--accent` / `--accent-2`；压在上面的文字色是 `--accent-ink` |
| 页面底色 | `--ground`（近黑偏青，**不要换成纯黑**） |
| 实体面 / 凹槽 | `--panel` / `--panel-2` / `--panel-3` / `--groove`（都是"上亮下暗"的不透明斜面） |
| 立体强弱 | `--key-top`（上沿受光）+ `--key-bottom`（下沿厚度）+ `--key-ground`（贴地短影） |
| 文字亮度阶梯 | `--ink` / `--ink-2` / `--ink-3` / `--ink-dim`（`--ink-dim` 是对比度地板，**不许再暗**） |
| 圆角 | `--r-sm/md/lg/xl`（内紧外松） |
| 历史页的环 | `style.css` 第 8 节（`.ring-{day,disc,svg,arc,tip,num,sets}`） |
| 销轨 | 同上（`.rail-*`） |
| 庆祝配色 | `plan-page.js` 顶部的 `FX_COLORS` |

> 整页只有一个色相。**部位色相（`--tone-*`）已经整组退场**——它原来只活在视频封面和录入工具里，那两个页面删掉之后就没有家了。

## 九、几个必须注意的规则

### 1. 每条之间要有逗号
数组里每一条 `{ ... }` 后面都要跟英文逗号 `,`，**最后一条可以不加**。漏逗号会导致白屏。

### 2. 只能用英文标点
`'` `"` `,` `:` —— 不要用中文的 `'` `"` `，` `：`。

### 3. 单引号里不能出现单引号
错误：`'动作里的'引号'会出问题'`
正确：`"动作里的'引号'没问题"`

### 4. 同一个肌群要写一样
一处写「背」、另一处写「背部」，部位卡里就会出现两个选项。

### 5. 白屏了怎么办
按 `F12` 打开控制台，红色报错会告诉你是哪一行、什么符号写错了。
